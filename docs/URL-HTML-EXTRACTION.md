# Извлечение HTML-области по URL — этап 3

## Назначение

БАР может анализировать не всю страницу сайта, а один выбранный HTML-контейнер.
Это особенно важно для публикаций на платформах, где автор управляет содержимым
статьи, но не управляет навигацией, боковыми панелями, комментариями и другими
элементами шаблона.

## Профиль VC.ru

Если URL относится к `vc.ru` или его поддомену и пользователь не задал свой
селектор, БАР использует:

- контейнер статьи: `.content__body`;
- заголовок публикации: `.content-title`.

Текст `.content-title` передаётся одновременно в аналитические зоны **Title** и
**H1**. В общей зоне `all` заголовок учитывается один раз. Извлечённый H1 не
добавляется повторно в основной текст.

Внутри `.content__body` формируются отдельные зоны:

- `title` — заголовок публикации из `.content-title`;
- `h1` — тот же заголовок как структурный H1;
- `headings` — H2–H6;
- `text` — текстовые блоки без повторного включения заголовков и текста ссылок;
- `anchors` — подписи ссылок внутри статьи;
- `all` — заголовок один раз и содержимое выбранного контейнера.

Навигация, боковые блоки, комментарии, рекомендации, футер и прочие элементы вне
`.content__body` не попадают в анализ. Внутренние изображения не преобразуются в
текст по атрибуту `alt`; текстовые подписи к медиа-блокам остаются частью статьи.

## Другие сайты

Поле **CSS-селектор области анализа** позволяет указать собственный селектор.
Поддерживаются селекторы тегов, классов, идентификаторов, атрибутов, потомков,
прямых дочерних элементов и группы через запятую. Псевдоклассы и соседние
комбинаторы не поддерживаются.

Явно заданный селектор обязан найти ровно один контейнер. Если контейнер не
найден или найдено несколько совпадений, БАР возвращает понятную ошибку и не
переключается на анализ всей страницы. Если поле пустое, для сайтов вне VC.ru
сохраняется автоматический выбор основной области (main/article/body).

Для обычных собственных сайтов метатег `<title>` остаётся зоной Title, а H1
внутри выбранного контейнера анализируется отдельно. Исключение — профиль VC.ru,
где `.content-title` является заголовком публикации и источником Title/H1.

## Предварительный просмотр

`POST /api/extract-preview` принимает:

```json
{
  "url": "https://vc.ru/example/123",
  "selector": ""
}
```

Ответ показывает фактически выбранный селектор, профиль, Title/H1, количество
заголовков, текстовых блоков, ссылок и слов, оценку качества и фрагмент
извлечённого текста. Предпросмотр не запускает XMLRiver и не строит полный отчёт.

При запуске анализа поле `ownPage.selector` передаётся в `/api/analyze-run` и
применяется только к анализируемой странице пользователя. Конкуренты по-прежнему
извлекаются штатным автоматическим способом.

## Проверки

Регрессионные тесты находятся в `tests/html-content-extractor.test.mjs`.
Они проверяют профиль VC.ru, совпадение Title/H1, отсутствие двойного учёта
заголовка, извлечение ссылок и подзаголовков, пользовательский CSS-селектор,
исключение внешних элементов и отказ от небезопасного fallback на всю страницу.
